# 張雅婷 Claire Chang - 個人履歷網站

> 品牌公關接待專員 / VIP 客戶關係管理 / 品酒文化與美學款待

本專案為張雅婷 (Claire Chang) 的個人履歷官方網站，採用質感大地美學（Warm Earth Tone Aesthetic）設計，並支援響應式排版（手機、平板與電腦）及一鍵列印/匯出 PDF 履歷功能。

## 🌟 網站特色

- **設計風格**：溫暖細膩的大地色系（沙色、陶土褐、鼠尾草綠與炭灰），呈現高雅專業的公關與品酒氛圍。
- **響應式設計**：支援 Mobile / Desktop 完美瀏覽。
- **功能性**：
  - 一鍵複製聯絡資訊與郵件快速發送
  - 專屬列印樣式（支援直接儲存為排版乾淨的 A4 PDF 履歷）
  - 流暢滑動錨點導航
